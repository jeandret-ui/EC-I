CGI Project Hub v12

Your projects, schedules, meetings, procurement, FAT/SAT, RACI, costing and quote register — in one local dashboard.

1 · Open it

  1. Keep this whole folder together (including runtime). A good place is C:\CGI\CGI_Project_Hub.
  2. Double-click CGI Project Hub.vbs. The hub opens in your browser and a CGI Project Hub shortcut appears on your desktop.
  3. Next time, just use the desktop shortcut. It works offline; nothing is installed.

Stop it from Settings › Stop the hub or with Stop CGI Project Hub.bat. Problems? Run Start CGI Project Hub (console).bat to see messages.

2 · Your data

All project information is saved in
C:\Users\Jeandre.t\OneDrive - Instramac\Desktop\Local Dashboard Storage

  • Projects\<code - name>\ — schedule, actions, meetings & minutes, RACI, procurement, tests, commercials (Registers), costing documents (Costing), files (Documents), notes (Tracker), change log and daily snapshots.
  • Commercial\ — the company quote register and costings not yet linked to a project.
  • Change the location in Settings or in storage_location.txt. Back up by copying the folder.

4 · Tips

  • Press / to search the current project. Use + (top right) to add anything quickly.
  • Start a new project from an awarded job in the quote register to pre-fill client, PO, value and contact.
  • Set your name in Settings so “My work” shows your items first.
  • Drop files straight into a project's Documents folder in Explorer — they appear in the app.
